# Vali Basha Shaik Portfolio

This repository contains an immersive 3D portfolio experience built with Vite + React + Three.js.

## Features
- First-person exploration environment
- Natural terrain, trees, water, and mansion-inspired structures
- Interactive portfolio sections for About, Skills, Projects, Internships, Content, and Contact
- Responsive overlay UI with keyboard/mouse controls
- Start screen and pointer-lock exploration flow

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Notes
The portfolio uses the existing repository information and social links supplied by the owner. Update the data in `src/App.jsx` whenever details change.
